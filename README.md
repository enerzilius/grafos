# ALGORITMOS EM GRAFOS

Esse repositório contém as implementações cm C++ de conceitos apresentados nas aulas da matéria Algoritmos em Grafos.

## Estrutura

- `/structures` contém as implementações de grafos de lista de adjacência.
- `/algorithms` contém `search` que implementa técnincas de busca apresentadas em aula e `graph_statistcs` faz a implementação do trabalho que escreve a eccentricity e a closeness centrality de todos os nós em arquivos `.txt`.
- `/utils` contém o parser usado para ajudar na interpretação de arquivos `.gexf` pelos grafos.
- `/data` contém dados em `.txt` ou `.gexf`.
- `/build` vai ter o resultado da compilação dos arquivos.

## Executar

Para executar o projeto só é necessário os seguintes comandos:

- `$ make`
- `$./build/main.out`
